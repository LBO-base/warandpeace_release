# Настройка конфига

*Read in English: [config.md](config.md)*

## Файл конфига

Мод создаёт конфиг при первом запуске:

```
<Valheim>/BepInEx/config/com.rarier.warandpeace.cfg
```

Редактируй его **при закрытой игре (или выключенном сервере)** — BepInEx читает
файл на старте. У каждой строки в файле есть свой комментарий; здесь — те
настройки, которые реально крутят, по секциям.

**Мультиплеер:** вся симуляция идёт на сервере (в кооперативе — на хосте), и для
мира **главный — конфиг сервера**: количество поселений, войны, экономика.
Клиентские настройки (HUD, пины карты, клавиша панели) — личные.

Обновляешься с *WarAndPiece* 0.4.x? Старый `com.rarier.warandpiece.cfg` и папка
`config/WarAndPiece` переезжают автоматически при первом запуске.

## Горячие клавиши

| Клавиша | Что открывает | Настройка |
|---------|---------------|-----------|
| **H** | Панель поселения — паспорт ближайшего города: экономика, гарнизон, войны, здания, фракции | `[HUD] SettlementPanelKey` |
| **F7** | Студия шаблонов — сохраняй свои постройки как чертежи для всего мира ([гайд строителя](building-guide.ru.md)) | `[Debug] LayoutStudioKey`, только хост |
| **F9** | Полигон — вызови армию любой фракции на ближайший город и сравни прогноз с живым боем | `[Debug] CalibPanelKey`, только хост |

Для F7/F9 нужен также `[Debug] EnableAdminPanel = true` (по умолчанию включён).

## [World] — сколько мира

| Настройка | По умолч. | Смысл |
|---|---|---|
| `EnableWorldSpawning` | true | Главный рубильник: выключен — новые поселения не появляются вовсе. |
| `MaxSettlements` | 120 | Жёсткий потолок числа поселений в мире. |
| `PlanWholeWorld` | true | Планировать всю карту при загрузке мира (города существуют «на бумаге» и материализуются при подходе). Выключено — поселения только у разведанных зон. |
| `PlanSpacing` | 450 | Минимальная дистанция между городами, метры. Больше = реже мир. |
| `MinDistanceFromWorldCenter` | 700 | Защитный радиус вокруг спавна — там NPC-городов нет. |

**Плотнее мир:** `PlanSpacing 350`, `MaxSettlements 160`.
**Реже мир:** `PlanSpacing 600`, `MaxSettlements 80`.

## [Settlement] — как строятся города

| Настройка | По умолч. | Смысл |
|---|---|---|
| `FriendlyChance` | 0.68 | Доля цивилизованных (викингских) поселений против рейдерских лагерей. |
| `EnableTraders` | true | Торговцы у флага цивилизованных городов. |
| `LevelTerrain` | true | Терраформинг: террасы, насыпи под дома, рампы. Выключено — дома подстраиваются под голый рельеф. |
| `AdaptivePlacement` | true | Дома сами ищут пятачки на естественном рельефе (рекомендуется). Выключено — плоские штампованные террасы. |
| `AdaptiveWalls` / `AdaptivePaths` | true | Частокол по периметру и грунтовые дорожки между домами. |
| `SettlementHeartPrefab` | crystal_wall_1x1 | «Сердце» цивилизованного города — объект, который захватывают. |

## [War] — сколько войны

| Настройка | По умолч. | Смысл |
|---|---|---|
| `EnableWars` | true | Живые набеги на поселения рядом с игроками. |
| `EnableWarSim` | true | Война всей карты: армии, осады, завоевания везде. |
| `WarSimTickSeconds` | 45 | Темп мировой войны. Больше = медленнее кампании. |
| `WarSimMobilizeThreshold` | 50 | Сила сбора, с которой город выступает в поход. Выше = войн меньше, но крупнее. |
| `WarCooldownMinutes` | 18 | Передышка между набегами на один город. |
| `EnableSeaBattles` | true | Армии на воде можно перехватить в морском бою. |
| `WaveCapOutpost/Village/Town/Capital` | 4/6/8/10 | Максимум атакующих тел за волну штурма при игроке (защита производительности). |

**Мирный мир:** `EnableWarSim false` — экономика и караваны живут, завоеваний нет.
**Медленнее война:** `WarSimTickSeconds 90`, `WarSimMobilizeThreshold 80`.

## [Economy], [Buildings], [Workers]

| Настройка | По умолч. | Смысл |
|---|---|---|
| `EcoTickSeconds` | 60 | Пульс экономики: производство, найм, ремонт. |
| `ProductionMultiplier` | 1.0 | Глобальный множитель производства всех городов. |
| `ConquestLootFraction` | 0.6 | Доля казны разграбленного города, которую уносит победитель. |
| `[Buildings] *` | — | Бонусы зданий по ролям (еда с ферм, металл шахты, сбор казармы…). Это цифры за вкладкой «Здания» панели H. Повреждённые здания дают пропорционально меньше; руины не дают ничего, пока не отстроены. |

## [Capture] — твои города

| Настройка | По умолч. | Смысл |
|---|---|---|
| `EnableCapture` | true | Разбил беззащитное сердце врага — город твой. |
| `AllowSettlementLoss` | true | NPC-армии могут захватывать **твои** города. Выключено — твой город может проиграть бой, но не флаг. |
| `ForcePvP` | false | Оставь выключенным — PvP-захват намеренно не поддерживается. |

## [Roads] — дороги и караваны

| Настройка | По умолч. | Смысл |
|---|---|---|
| `EnableRoads` | true | Города строят настоящие дороги друг к другу. |
| `EnableCaravans` | true | Торговые караваны с реальным грузом (их можно грабить — и тебе тоже). |
| `RoadPainting` / `RoadGrading` | false | Дорожное покрытие/планировка, трогающие террейн; выключены, чтобы мир оставался нетронутым. |

## [HUD], [Map], [Performance]

| Настройка | По умолч. | Смысл |
|---|---|---|
| `EnableHUD` | true | Полоса фракции/поселения сверху экрана. |
| `EnableMapPins` | true | Гербы поселений, пины армий/караванов/работников на карте. |
| `MaxLiveNpcs` | 250 | Глобальный потолок живых NPC мода — снижай на слабых машинах. |

## [Reputation]

Как города судят тебя: удары по постройкам и NPC поселения стоят локальной и
фракционной репутации (`RepLossPerHit*`), убийство рейдеров у города её
приносит (`RepGainPerRaiderHit`), репутация ниже `RepHostileThreshold` (−20) —
стража бьёт на месте. Дары в сундук даров поднимают её обратно.

## Полезные консольные команды (F5, хост)

| Команда | Эффект |
|---|---|
| `wap_settlements` | Дамп всех поселений в `settlements.txt` (с сидом мира). |
| `wap_reset` | Полный сброс симуляции: объекты мода стираются, города игрока остаются, мир планируется заново. |
| `wap_terrainfo` | Встань в разрыв террейна — покажет, в какой зоне правки. |
| `wap_terrareset [радиус]` | Вернуть террейн вокруг тебя к природному (высоты + краска). |
| `wap_prefabs <фильтр>` | Поиск имён префабов (например, для `SettlementHeartPrefab`). |
