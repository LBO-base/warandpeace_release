# Настройка выделенного сервера (dedicated)

*English: [server-setup.md](server-setup.md)*

## Требования
- Valheim Dedicated Server (Windows или Linux).
- BepInEx 5.4.22+ для Valheim (серверная установка).
- Мод обязателен **на сервере и на каждом клиенте**, версии должны совпадать —
  при расхождении мод предупредит игрока в чате при входе.

## Установка на сервер
1. Установи BepInEx в папку сервера (тот же пакет, что для клиента; на Linux —
   запуск через `start_server_bepinex.sh`, он есть в нашем ките).
2. Положи `WarAndPeace.dll` в `BepInEx/plugins/` сервера.
3. Запусти сервер. При первом старте создастся конфиг:
   `BepInEx/config/com.rarier.warandpiece.cfg`.

## Как это работает
- Вся симуляция (ворлдген, экономика, войны, армии) считается **на сервере**.
  Конфиг сервера — главный; клиентские настройки влияют только на интерфейс.
- Состояние мира хранится в `BepInEx/config/WarAndPeace/<мир>.settlements.txt`
  рядом с конфигом. Бэкапь его вместе с миром.
- Файл привязан к сиду мира: чужой файл с тем же именем мира сервер отложит в
  `.bak` и начнёт с чистого листа.

## Обновление сервера
1. Останови сервер.
2. Замени `BepInEx/plugins/WarAndPeace.dll` на свежий из `latest/` этого репо.
3. Обнови мод у всех игроков (батник из кита).
4. Запусти сервер.

## Советы
- Рекомендуемый размер компании — до 5 игроков.
- Первый заход на новый мир: мод спланирует ~150 поселений — это одна строка в
  логе и несколько секунд; города строятся по мере того, как игроки их находят.

## Свои здания на сервере
Здания генерятся **сервером**, поэтому и библиотека зданий живёт на сервере:

1. Возьми `.wapx`-файлы (свои — из Студии F7, чужие — от сообщества).
2. Положи их на сервере в `BepInEx/config/WarAndPeace/layouts/`.
3. Перезапусти сервер — новые шаблоны попадут в пул и будут появляться в
   поселениях при генерации, росте и перестройке после войн.

Игрокам ставить эти файлы **не нужно** — здания приходят к ним как обычные
постройки мира. Уже сгенерированные города новые шаблоны подхватят при
следующем росте/перестройке; свежий мир возьмёт их сразу.
